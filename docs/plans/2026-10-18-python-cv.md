# Python function values (CV-1, CV-2, CV-4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Python code gets CALLS edges for function values handed to a listed
invoker (CV-1, by position or keyword), held in a local and called (CV-2), or
handed to an own function that calls that parameter (CV-4).

**Architecture:** The core resolver already turns `value-arg:` / `value-local:`
raw edges into calls (`resolver/engine.py::_value_call_edge`). The core learns
keyword slots, a builtin invoker that does not resolve, and invokers read from a
node's `metadata["invokes"]`. The Python pack gets a profile and one new module,
`_values.py`, that runs per function after the walk and emits the candidates and
`invokes`.

**Tech Stack:** Python 3.12, tree-sitter-python, pytest, strict mypy, ruff.

**Spec:** `docs/specs/2026-10-18-python-cv-design.md` (revision 2). Clause
texts: `docs/specs/core/ontology.yml`.

## Review Focus

1. A parameter or plain local whose name equals a project function (`handler`,
   `callback`) passed to any call: no edge to that function. → Task 3
   `cv4-param-shadows-function`, plus `test_a_parameter_named_like_a_function_is_no_value`.
2. A project function named like a builtin invoker (`def map(...)`) called with a
   function argument: the call resolves to the project `map`, which is not an
   invoker unless it calls that parameter. → Task 1
   `test_a_shadowed_builtin_is_not_the_builtin_invoker`.
3. An own invoker that is a decorated method (`@retry`, `@classmethod`) or
   `async def`: its slots are counted correctly (first parameter skipped for
   `@classmethod`, not for `@staticmethod`). → Task 3 `cv4-classmethod-invoker`,
   `cv4-staticmethod`.
4. A call with a comment, a `*xs` splat or `**kw` among its arguments: positions
   after a splat are skipped, a comment shifts nothing. → Task 3
   `test_slots_skip_comments_and_stop_after_a_splat`.
5. An incremental ingest after only the caller file changed: the invoker node
   comes from the store and still carries `invokes`. → Task 2
   `test_an_invoker_read_back_from_the_store_still_invokes`.

  - `value_candidates(func: BaseNode, code: bytes, source_id: str, file_path: str, file_names: frozenset[str], held: Callable[[BaseNode], list[str]] | None = None) -> list[Edge]`

  `function_definition`, `lambda` or `class_definition`. `shadowed` = the
  function's parameter names plus names it assigns.

  and no assignment to it precedes the first such call in source order.
  Positions skip the first parameter of a non-static method, stop at `*args`
  (later ones are keyword-only), and positional-only (`/`) ones get no name.
- Site string: `<raw call name>@<row>:<col>` of the `call` node, raw call name =
  `get_identifier(call.function)` as `process_call_node` uses.
